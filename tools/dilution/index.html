    How it is calculated

    The Formula, the Assumptions, and Where It Stops

    1. Concentrate per bottle = bottle volume × a ÷ (a + b), for a ratio of a:b.
    2. Water per bottle = bottle volume − concentrate.
    3. Cost per bottle = concentrate cost per litre × concentrate volume.

    Assumptions. Ratios are volumetric. A surfactant system may need a different ratio than a generic guide suggests.

    Standards we work to. ISO 9001:2015 (quality system, cert PCC85724Q01277R1S) · EU 10/2011 (plastic food-contact, migration report E2032) · RoHS (PE B-R01612E2033, PET B-R201133464) · ISO 4180 (packaging for transport). The calculator is a planning tool: the approved drawing and the migration report decide the final specification.

    Where it does not apply. It does not validate the formula — dilution stability is a lab question, not a packaging one.

    Why Refill Concentrate Changes the Pack

    A 1:10 concentrate sold in a 250 ml bottle makes 2.75 litres of ready-to-use cleaner. That changes both the container (small, thick-wall, measuring cap) and the shipping cost per litre of use.

    The Bottle Still Has to Survive the Chemistry

    Alkaline and solvent concentrates need HDPE and a specified trigger gasket; PET is only for mild, near-neutral formulas.

    Questions About This Tool

    What ratio should I use?

    Typical household cleaners run 1:5 to 1:20; the label and the surfactant system decide.

    Which bottle for concentrate?

    250–500 ml HDPE with a measuring cap and a 38 mm neck.

    Can the trigger handle it?

    Specify the gasket material and test with the real concentrate, not water.
