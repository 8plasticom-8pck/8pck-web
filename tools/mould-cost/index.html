    How it is calculated

    The Formula, the Assumptions, and Where It Stops

    1. Base band per part: small USD 1,900–3,700 · medium 3,200–6,400 · large 4,700–9,500.
    2. Multiply by part count, then by the cavity multiplier (1x / 1.6x / 2.6x).
    3. Add a plating jig allowance where a metal finish is specified.
    4. Add 30–45 % where a thread must be unscrewed rather than stripped.

    Assumptions. One cavity per part unless stated; standard steel and polishing; no hot runner.

    Standards we work to. ISO 9001:2015 (quality system, cert PCC85724Q01277R1S) · EU 10/2011 (plastic food-contact, migration report E2032) · RoHS (PE B-R01612E2033, PET B-R201133464) · ISO 4180 (packaging for transport). The calculator is a planning tool: the approved drawing and the migration report decide the final specification.

    Where it does not apply. It is a budget band. A drawing review sets the real number, and a complex seal or an off-axis thread can move it further.

    Why Part Count Dominates

    Every part is a separate mould, a separate trial, and a separate tolerance stack. Four small parts cost roughly four times one part — the size of the part matters less than how many there are.

    The Unscrewing Penalty

    If a lid has an internal thread it cannot be stripped off the core; the mould needs a rotating mechanism, which is where a 30–45 % jump comes from.

    Questions About This Tool

    What does a custom bottle mould cost?

    One cavity, one part: USD 1,850–9,500 depending on size and thread. A four-part assembly is typically USD 16,000–27,500.

    Can I start with one cavity?

    Yes, and for under 10,000 pcs a year it is the right choice — a second cavity rarely pays back.

    Is tooling refundable?

    No. It is a one-off cost, amortised over the first run.
